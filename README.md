# 📚 Gemini AI Study Assistant

An AI-powered Python utility designed to help students streamline their exam preparation. By leveraging Google's Gemini API, this tool automatically processes long lecture notes, textbook extracts, or topic transcripts to generate concise summaries and practice quizzes.

---

## 🌟 Key Features
* **Automated Summarization:** Extracts core concepts into a concise 3-bullet point executive summary.
* **Quiz Generation:** Creates 3 tailored practice questions complete with an answer key for active recall testing.
* **Powered by Gemini:** Utilizes the `gemini-2.5-flash` model for high-speed, accurate academic analysis.

---

## 🛠️ Tech Stack & Prerequisites
* **Language:** Python 3.9+
* **SDK:** `google-genai`
* **API:** Google Gemini API (via Google AI Studio)
